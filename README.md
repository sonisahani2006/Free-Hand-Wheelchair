# Free-Hand-Wheelchair

**1. Introduction**

A free-hand smart wheelchair is an advanced mobility system designed for physically challenged and elderly individuals. It enables hands-free movement using voice commands along with manual control options, improving independence and ease of use.

**2. Working Principle**

 * The wheelchair operates using voice control and joystick control.
 * In voice mode, users give commands like forward, backward, left, right, and stop.
 * A microcontroller (NodeMCU) processes these commands and controls the motors.
 * In joystick mode, users can manually navigate the wheelchair.
 * The system allows switching between both modes for flexibility.

**3. Components Used**

 * Arduino UNO
 * NodeMCU (Main controller)
 * Bluetooth Module (HC-05)
 * Joystick Module
 * Motor Driver (L298N)
 * DC Motors
 * Ultrasonic Sensors (Obstacle detection)
 * MPU 6050 (Fall detection)
 * Buzzer (Alert system)
 * Power Supply

**4. Key Features**

 * Voice-controlled movement
 * Manual joystick control
 * Obstacle detection with buzzer alert
 * Fall detection system
 * Wireless communication using Bluetooth
 * Dual-mode operation (automatic + manual)
